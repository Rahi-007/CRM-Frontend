# Seema's Cloud Talk – Frontend

Seema's Cloud Talk is a modern web application built with Next.js, designed to provide an intuitive interface for managing clients, teams, projects, and business operations, with reporting and analytics features.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Redux Toolkit
- React Hook Form & Zod

## Key Features

- Authentication and protected routes
- User, team, client, and project management
- Role-based access control
- Interactive dashboard and reports
- AI/ML-assisted reporting and analytics
- Real-time online user presence using SignalR
- Responsive UI with reusable components

## Getting Started

Install dependencies:

```bash
npm install
```

Configure the required environment variables in `.env.local`, then start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Backend

The frontend connects to an ASP.NET Core backend API.

**Backend Repository:** [GitHub Repo](https://github.com/Rahi-007/CRM-Backend)

**Database:** PostgreSQL hosted on Neon.
